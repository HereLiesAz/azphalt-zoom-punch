# Zoom Punch

Radial motion blur streaking out from centre, pulsing in and out — the impact hit used on drops and reveals.

An [azphalt](https://github.com/HereLiesAz/azphalt) extension for
[Guillotine](https://github.com/HereLiesAz/Guillotine).

- **Package id** — `com.hereliesaz.azphalt.zoom-punch`
- **Version** — 1.0.0
- **Kind** — asset (ISF fragment shader)
- **Tags** — `shader`, `distortion`, `zoom-blur`, `radial`, `impact`, `one-click`

## Controls

| Parameter | Label | Range | Default |
| --- | --- | --- | --- |
| `amount` | Blur | 0.0 – 1.0 | 0.45 |
| `speed` | Pulse speed | 0.0 – 3.0 | 1.0 |

## Install

Open **Azphalt Store** inside Guillotine, find *Zoom Punch*, and tap **Install**. The effect is
applied to the selected clip.

To install manually, pack this directory as a `.azp` (a plain ZIP with `manifest.json` at the root)
and side-load it from the store's *Install from file* action.
